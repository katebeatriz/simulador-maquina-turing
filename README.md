# Simulador de Máquina de Turing

Projeto prático desenvolvido para a disciplina de Teoria da Computação.

## Como executar

1. Certifique-se de ter o Python 3.10+ instalado.
2. Clone este repositório.
3. Configure a máquina no arquivo `configuracao.py`.
4. Execute o programa principal:
   ```bash
   python main.py
